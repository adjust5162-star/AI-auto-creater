# Design System

## Direction

Quiet SaaS interface for repeated video-production work. The UI prioritizes readable forms, visible job state, and editable scene rows.

## Foundations

- Typography: system sans-serif.
- Radius: 6-8px for buttons, panels, and scene items.
- Primary action: signal blue.
- Status colors: blue for rendering, green for completed, coral for failed, amber for warnings.
- Layout: mobile-first single column, desktop two-column workspace.

## Components

- Buttons use icon plus concise label.
- Project and scene items use compact bordered surfaces.
- Inputs keep labels visible.
- Progress uses a real job-state percentage only.
